# MITRE ATT&CK Cloud mapping guidance

Category: threat-framework

## Map observed behaviours conservatively

MITRE ATT&CK describes adversary tactics and techniques. CloudSentry may suggest relevant technique references when observed behaviours and evidence fit, but a technique match is a classification aid rather than proof that an adversary conducted the activity.

For cloud environments, investigate identity and credential changes, privilege escalation, valid-account use, defense evasion, and changes that impair logging when the event evidence supports those interpretations. Include the technique name and official reference in a report only when the mapping is justified by the observable behaviour. Otherwise state that mapping is tentative or unavailable.
