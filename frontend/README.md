# Vigilix AI — SOC Dashboard Console

Cyber-glassmorphism security operations console built with React 19, Vite, and Lucide Icons.

## Features
- **Overview Telemetry:** Real-time metrics, risk severity breakdowns, and timestamp distribution charts.
- **Event Explorer:** Live event streaming, virtual pagination, JSON inspection, and multi-field filtering.
- **AI Copilot:** Conversational AI SOC assistant with markdown streaming, copy actions, and context awareness.
- **Automated Investigations:** One-click LangGraph incident triage with defensive containment checklists.
- **AWS Connectors:** Read-only connection status and synchronization for CloudTrail, S3, GuardDuty, and Security Hub.

## Development

```bash
npm install
npm run dev
```

Runs the development server at `http://localhost:5173`.

## Build

```bash
npm run build
```

Generates optimized production assets in `dist/`.
